\section{Discusión}

\subsection{Elección del stack}
El tándem Spring Boot + React maximizó productividad y separación de responsabilidades; la evidencia comparativa apoya esta decisión en escenarios empresariales y educativos \cite{estudio_aplicaciones_java}\cite{analisis_comparativo_java}.

\subsection{Experiencia de usuario}
Un diseño responsivo consistente reduce curva de aprendizaje y errores, en línea con lo reportado para Bootstrap y patrones de UI modernos \cite{optimizacion_bootstrap}\cite{analisis_frameworks_frontend}.

\subsection{Estrategia de datos}
Un modelo normalizado favorece integridad y consultas reproducibles para analítica \cite{analisis_google_charts}.

\subsection{Escalabilidad}
La estandarización para microservicios sugiere ganancias considerables en escenarios de lectura intensiva; no obstante, se recomienda un paso gradual para evitar complejidad prematura \cite{implementacion_microservicios}.

\subsection{Limitaciones}
Datos maestros en consolidación (áreas, cargos), reportes analíticos iniciales, pruebas de carga pendientes y definición de políticas de retención documental.
